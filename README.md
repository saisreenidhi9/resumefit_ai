# ResumeFit AI

An AI-powered resume screening application built using Python and Streamlit.

## Features
- Resume screening and scoring
- Job description matching
- Skill extraction and job recommendations
- Screening results dashboard

## Technologies
- Python
- Streamlit
- Machine Learning
- NLP
- SQLite

## Setup
1. Install dependencies:
   pip install -r requirements.txt

2. Run the application:
   streamlit run app.py
